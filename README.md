# API de prueba

## Descripcion

    Este proyecto fue creado para poner a prueba y practicar mi stack

## Tecnologias utilizadas

    - Node.js
    - Express
    - Express Validator
    - PostgreSQL
    - Sequelize
    - Squelize-Cli
    - JWT
    - Jest y Supertest
    - Swagger
    - Dompurify
    - Helmet
    - Cors
    - Cross-env

## Requisitos previos

Antes de instalar y ejecutar el proyecto, es necesario contar con:

    - Node.js
    - Pnpm
    - PostgreSQL
    - Git
